# প্রিভিউ উইন্ডো দেখার সুবিধা:

অভ্র ফোনেটিকে আপনি কি লিখছেন দেখার জন্য প্রিভিউ উইন্ডো পাবেন। ছোট্ট এই উইন্ডোটি আপনার সুবিধার জন্য যেখানে লিখছেন সেইখানে কিবোর্ড কার্সর (Caret) এর ঠিক নিচেই থাকবে। প্রিভিউ উইন্ডো একই সাথে আপনি কী লিখছেন সেটা দেখতে সাহায্য করে এবং ডিকশনারি সাজেশন দেখায়।
