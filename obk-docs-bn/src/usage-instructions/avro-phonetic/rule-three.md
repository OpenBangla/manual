# নিয়ম ৩: ব্যঞ্জনবর্ণের সংক্ষিপ্ত রূপ ("ফলা") ও অন্যান্য লেখা-

**ব-ফলা:** ব-ফলা লিখতে ব্যঞ্জনবর্ণের পরে "w" ব্যবহার করুন। উদাহরণ: বিশ্ব (bishwo), উদ্বায়ী (udwayI)

  - কিছু কিছু ক্ষেত্রে "w" ছাড়াই "b" দিয়ে আপনি ব-ফলা লিখতে পারবেন। উদাহরণ: আম্বিয়া (ambia/ambiya), বাল্ব (balb)

**য-ফলা:** য-ফলা লিখতে ব্যঞ্জনবর্ণের পরে "y" ব্যবহার করুন। উদাহরণ: ব্যবহার (bybohar), ব্যক্তি (byakti)

- লক্ষ করুন, "য়" লিখতেও আপনি "y" ব্যবহার করছেন। এটি য-ফলার সাথে সমস্যা তৈরি করবে না। অভ্র ফনেটিক যেখানে যা উপযোগী তাই লিখবে। উদাহরণ: ব্যবহার (bybohar), নিয়ম (niyom)
- আপনি "Z" (capital) ব্যবহার করে জোরপূর্বক যে কোন স্থানে য-ফলা লিখতে পারবেন, এভাবে উপযুক্ত স্থানে স্বরবর্ণের পরেও য-ফলা লেখা সম্ভব। উদাহরণ: অ্যাডমিন (aZDmin), অ্যারোমেটিক (aZromeTik)

**র-ফলা:** র-ফলা লিখতে ব্যঞ্জনবর্ণের পরে "r" ব্যবহার করুন। উদাহরণ: প্রসন্ন (prosonno), প্রায় (pray), প্রতিদিন (protidin)

**ম-ফলা:** ম-ফলা লিখতে ব্যঞ্জনবর্ণের পরে "m" ব্যবহার করুন। উদাহরণ: পদ্মা (podma)

**রেফ:** রেফ লিখতে ব্যঞ্জনবর্ণের আগে "rr" ব্যবহার করুন। উদাহরণ: অর্ক (orrko), আর্তনাদ (arrtonad), অর্থহীন (orrthohin)

**হসন্ত:** হসন্ত লিখতে দুইটি কমা, পরপর ব্যবহার করুন।

**দাড়ি:** দাড়ি (।) লিখতে ইংরেজি Full stop "." ব্যবহার করুন।

**টাকা (৳) চিহ্ন:** টাকা চিহ্ন লিখতে ইংরেজি Dollar "$" চিহ্ন ব্যবহার করুন।

**ডট (.) চিহ্ন:** অভ্র ফনেটিক এ শুধু ডট (.) দিয়ে আপনি দাড়ি লিখেন। এখন ডট (.) লিখতে ইংরেজি Full stop "." এর পরে Accent Key ব্যবহার করুন। অর্থাৎ ".`" লিখুন।

- অভ্র ফনেটিক এ আপনি Number Pad থেকে সরাসরি ডট (.) লিখতে পারেন। এক্ষেত্রে প্রতিবার স্বয়ংক্রিয়ভাবেই "." লেখা হবে।

**কোলন (:) চিহ্ন:** অভ্র ফনেটিক এ শুধু কোলন (:) দিয়ে আপনি বিসর্গ (ঃ) লিখেন। কোলনের পরে Accent Key চাপলেই তা বিসর্গ না হয়ে কোলন হয়ে যাবে। অর্থাৎ আপনাকে লিখতে হবে ":`"

এছাড়া অন্য যেকোনো যতি/ছেদ (Punctuation mark) বা অন্য কোন চিহ্ন যেমন ; ?! () {} [] / \ + - \* % ইত্যাদি
সাধারণভাবেই লেখা যাবে।
